Health Check

Once a day, shortly after the nightly backup, this app checks itself — that backups are running and restorable, that the backup folder is writable, and that the disk isn't full — and shows a warning on the Dashboard if something needs attention.

Remote Monitoring (optional)

Off unless you fill this in. When set, this clinic sends a short daily status ping — counts and statuses only, never patient, owner or staff details, and never any amounts. The point is the missing ping: if this machine stops sending, whoever maintains the system gets told, which is the one thing the app cannot report while it is switched off.

Must start with https://. Use a different URL for each clinic, so an alert can say which one went quiet. Treat it like a password — anyone who has it can send a fake ping and stop a real alert from ever reaching you.

Restore From Backup

Replaces all current data in VetClinicSystem JO with the contents of a backup file. This can't be undone — take a fresh backup first if you're not sure. Uploaded files (X-rays, lab results) aren't part of the backup itself and are unaffected by a restore, but any that were attached after the backup being restored was taken will need reconnecting — run python3 reconcile_attachments.py from the app folder afterward to find and relink them safely.
